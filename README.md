# Нумерация токенов для Owlbear Rodeo

Расширение рисует маленькие полупрозрачные номера в углу токенов. Номера видит только мастер: они рисуются локально в его браузере и игрокам не передаются.

## Как подключить

Owlbear Rodeo подключает расширения по ссылке на `manifest.json`, поэтому папку нужно выложить в интернет.
Файлы должны лежать в корне сайта (адрес вида `https://имя.netlify.app/manifest.json`).

1. Выложите всю папку на любой статический хостинг: Netlify Drop, Cloudflare Pages или GitHub Pages
   (для GitHub Pages — репозиторий с именем `ваш-ник.github.io`).
   Файл `_headers` уже лежит в папке: Netlify и Cloudflare Pages используют его, чтобы разрешить Owlbear загрузить расширение.
2. В Owlbear Rodeo откройте меню профиля, выберите добавление расширения и вставьте ссылку на `manifest.json`.
3. Включите расширение в нужной комнате. Игрокам ничего ставить не нужно.

## Как пользоваться

- Выделите токены, откройте расширение (иконка с решёткой) и нажмите «Пронумеровать выбранные».
- Номера идут слева направо и сверху вниз, а при следующей нумерации счёт продолжается с максимального номера.
- «Считать отдельно для каждого имени» даёт гоблинам 1, 2, 3, а оркам тоже 1, 2, 3.
- Правый клик по токену на слое персонажей: «Пронумеровать» или «Убрать номер».
- Прозрачность, размер и угол настраиваются в окне расширения.
